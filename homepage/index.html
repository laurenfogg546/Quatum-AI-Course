How to use this course

  1. Click a Launch button above — the notebook opens right in your browser.
  2. Run each cell top-to-bottom with Shift + Enter, or use Run → Run All Cells.
  3. The first cell loads the libraries; give it a few seconds the first time.
  4. Edit the code in the activity cells and re-run to experiment — you can't break anything.
Everything runs locally in your browser using JupyterLite, so some heavier cells (training loops, kernel matrices) may take 30–60 seconds. A cell is still working while it shows [*].
